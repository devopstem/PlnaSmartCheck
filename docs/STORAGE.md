# Где что хранится

## 1. Room (SQLite) — смысл «базы» приложения

Путь внутри приложения: база `plna_smartcheck.db`.

| Таблица | Зачем |
|---------|--------|
| `expenses` | Все чеки и товары (JSON), флаг `synced` |
| `user_session` | 16-значный ID, имя, язык |
| `pending_cloud_deletes` | ID чеков, которые нужно добить в Firestore офлайн |

**Зачем Room, если есть Firebase?**  
Чтобы открывать чек-лист без интернета, быстро сохранять и не ждать облако. Облако — копия «на другой телефон» и бэкап.

## 2. OCR русский язык — не Room

Папка: `Android/data/...` → внутренний `files/tesseract/tessdata/`.

| Файл | Когда появляется |
|------|------------------|
| `rus.traineddata` | Первый OCR (или уже есть) |
| `eng.traineddata` | Первый OCR (или уже есть) |

Код проверяет: если файл есть и размер > 100 КБ → **скачивание пропускается**.

Повторно качает только если:

- удалили приложение;
- в настройках телефона нажали «Очистить данные»;
- файл битый / обрезанный.

Обычное обновление из Android Studio / Play **не** стирает эти файлы.
